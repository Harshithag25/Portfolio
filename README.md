Welcome to my personal portfolio! This website showcases my background, technical skills, projects, learning journey, and professional interests as an aspiring Data Scientist and Data Analyst.

## About the Project

A cinematic, chapter-based personal portfolio built using plain HTML, CSS, and vanilla JavaScript, with GSAP and Lenis for animations and smooth scrolling.

The website is designed with a modern dark aesthetic, interactive elements, responsive layouts, and engaging visual transitions.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP 3.12.5
- GSAP ScrollTrigger
- Lenis 1.1.13
- Google Fonts

No build step or framework required.

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Harshithag25/HARSHITHA-PORTFOLIO.git
   ```

2. Open the project folder:

   ```bash
   cd HARSHITHA-PORTFOLIO
   ```

3. Open `index.html` in your browser.

Alternatively, run a local server:

```bash
python -m http.server 8000
```

Visit: http://localhost:8000
